# 🌿 About The Project

**Hakaluki.dev** is a hands-on web development journey that documents the complete process of learning, building, deploying, and maintaining websites.

The project starts from the very beginning of web development and gradually moves toward real-world development practices.

We are not only learning how to write code.

We are learning how to take an idea:

```text
💡 Idea
   ↓
📋 Planning
   ↓
🧱 Structure
   ↓
🎨 Design
   ↓
💻 Development
   ↓
🧪 Testing
   ↓
🐛 Debugging
   ↓
📦 Version Control
   ↓
☁️ GitHub
   ↓
🚀 Deployment
   ↓
🌐 Production
   ↓
🔄 Maintenance
```

The ultimate goal is to understand the **complete lifecycle of a real-world website**.

---

# 🎯 Project Goals

Hakaluki.dev is being developed with several goals in mind.

### Primary Goals

* Learn web development from the fundamentals.
* Build real websites instead of only following tutorials.
* Understand proper project structure.
* Learn professional Git and GitHub workflows.
* Practice debugging and problem solving.
* Learn how websites are deployed.
* Understand domains, DNS, HTTPS and hosting.
* Learn how production websites are maintained.
* Gradually move from frontend to full-stack development.
* Document the entire development journey.

### The Main Philosophy

> **Don't just learn the syntax. Understand the entire process.**

# 📚 Learning Path

## 01 — 🧱 HTML Fundamentals

HTML is the foundation of the project.

We start by understanding how a webpage is structured.

### Topics

* HTML document structure
* Headings
* Paragraphs
* Links
* Images
* Buttons
* Lists
* Tables
* Forms
* Navigation
* Semantic HTML
* Attributes
* Multiple HTML pages
* Linking pages together

### Example

```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Hakaluki.dev</title>
</head>

<body>

    <nav>
        <a href="index.html">Home</a>
        <a href="products.html">Products</a>
        <a href="contact.html">Contact</a>
    </nav>

    <main>

        <h1>Welcome to Hakaluki.dev</h1>

        <p>
            Learning web development by building real projects.
        </p>

    </main>

</body>

</html>
```
